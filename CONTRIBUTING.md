# Contributing to StreamCtx

Thanks for your interest in StreamCtx! This is a solo-maintained, open-source project (MIT licensed), and contributions of any size are welcome — bug reports, docs fixes, tests, or features.

## Ways to Contribute

- **Report a bug**: Open a [GitHub Issue](../../issues) with a clear repro (Python version, OS, minimal code snippet).
- **Suggest a feature**: Start a thread in [Discussions → Ideas](../../discussions/categories/ideas) before opening a PR — helps avoid wasted work on things that don't fit the roadmap.
- **Ask a question**: Use [Discussions → Q&A](../../discussions/categories/q-a).
- **Fix a bug / add a test**: PRs welcome, see workflow below.
